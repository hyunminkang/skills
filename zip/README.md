# Upload-ready zips

Pick the folder for the product you upload to:

- `claude/`: Claude.ai and ChatGPT. The zip holds the skill folder
  (`<name>/SKILL.md`), so it can also be unzipped straight into a coding
  agent's skills folder (`~/.claude/skills/`, `~/.agents/skills/`).
- `gemini/`: Gemini. The zip holds `SKILL.md` at its root, which Gemini
  requires for skills with more than one file. Gemini accepts only some
  file types, so text files with other extensions get `.txt` appended
  (for example `checks.R` becomes `checks.R.txt`).

Both zips of a skill have the same content and include the license as
`LICENSE.txt`. They are generated by `python3 tools/build_zips.py` from
`skills/<name>/`, so edit the skill folder, not the zips.

Install steps for each app and agent: <https://hyunminkang.github.io/skills/install/>
